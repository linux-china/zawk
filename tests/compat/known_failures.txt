# Known differences between zawk and gawk, one case per line: `name  # reason`.
# These cases still run: the test fails if one of them starts passing, so remove fixed cases here.

# records and fields
01-crlf-default-fs                    # with the default FS, `\r` is a blank that separates fields (CRLF input splits cleanly)

# grammar and expressions
07-for-simple-statement-init          # a `for` header only accepts expressions, not simple statements such as print (POSIX allows print)
03-string-to-number                   # hexadecimal input such as "0x1A" converts to 26 instead of 0
03-strnum-comparison                  # a hexadecimal field ("0x1A") is a strnum and compares as 26
03-strnum-fields                      # a hexadecimal field ("0x0A") is a strnum and compares as 10
03-strnum-params                      # a string that looks like zero ("0", "0.0") is false, strnum or not (same as `??`)
03-strnum-truth                       # a string that looks like zero ("0", "0.0") is false, strnum or not (same as `??`)
03-ternary-and-logic                  # a string that looks like zero ("0", "0.0") is false, strnum or not (same as `??`)
03-uninit-udf-arg                     # an uninitialized number passed to a user-defined function reads as "0" (parameters are not tracked)
03-forin-key-is-string                # in `for (k in a)` over keys that are only numbers (`x[65]`), k is a number: %c prints "A" (see info/faq.md)

# printf
05-printf-c-strnum                    # %c of a hexadecimal strnum ("0x41") is the character with that code ("A")

# input and output
09-argv-delete-skip                   # ARGV/ARGC are read-only: changing them in BEGIN does not change the input files
09-getline-concat-precedence          # `getline < "a" "b"` reads the file "ab" (gawk: `(getline < "a") "b"`), and `cmd | getline x y` is a syntax error
